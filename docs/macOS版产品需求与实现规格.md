# PDF Desk macOS 版产品需求与实现规格

本规格用于从零实现可与 Windows 版对照验收的本地 PDF 桌面应用。功能基线为 2026-11-22 的 Windows 项目，应用版本 **0.0.47**，源码提交 `b781b64`。文中的 Windows 数值和文件表示用于复现行为；标为「macOS 方案」的内容是移植设计建议。路径均相对于 Windows 仓库根目录。

## 1. 产品范围和数据归属

用户可以从 Finder 打开原稿，也可以把资料复制到书库，在多个窗口阅读、填写和批注，最后按需保存、重组、压缩、分享或打印。核心流程离线运行，无需账户。以下三种数据的归属决定了「保存」「移除」「删除」各自的后果。

| 数据 | 写入时机与位置 | 验收 |
|---|---|---|
| PDF 内容 | 保存到当前文件或用户选定的副本。包括页面树、表单值、墨迹、文字标记、便签、文字框、图片、可见签名及其外观 | 把文件移到另一台机器，用独立 PDF 阅读器检查页序、文字和外观 |
| 书架和阅读状态 | 本地配置记录最近文档、收藏、书签、阅读位置、标签、窗口及设置。Windows 默认使用“文档”下的 `PDFDesk/PDFDesk.json`，书库默认为同级 `Library` | 只加收藏、书签或旋转阅读视图时，原 PDF 的字节保持一致；重启能恢复状态 |
| 素材、缓存和临时输出 | 可复用签名独立保存；封面可以重新生成；分享和导出使用临时文件；诊断日志保存在本机 | 清理封面后再开书架可重建；删除签名库素材后，已保存到 PDF 的签名仍可见 |

范围以当前可操作入口为准。扫描页依赖已有文字层才能选词、搜索和做文字标记；添加文字是创建新对象。数字签名面板展示文件声明和字节覆盖情况，未实现证书签发、信任链或密码学有效性验证。XFA 提供兼容性提示。引擎的可选密码参数不能据此视为已交付密码管理界面。

## 2. 打开文件、书架和收藏

| 编号与入口 | 用户行为、实现约束及验收结果 |
|---|---|
| F01 打开原文件 | 从主页、阅读窗口、系统文件关联、拖放或桌面菜单打开一个或多个 PDF。Windows 命令行先解析相对路径，支持文件列表和可选的 `--page`、`--zoom`。普通重复打开激活现有编辑标签。损坏文件显示本地化错误，随后仍可打开有效文件。 |
| F02 复制到书库 | 复制到当前书库后打开副本，以后保存写入副本。先写临时文件，再分配可用文件名，重名追加编号。区分已在书库内的路径。用两个不同目录下的同名 PDF 连续导入，验证原稿和先导入的副本均保留。 |
| F03 新建 | 用户输入名称，校验空名、非法名称及长度，生成带有一张 A4 纵向空白页的有效 PDF（595.28 × 841.89 pt）。在书库生成可用文件名并打开，可直接写字、签名和保存。 |
| F04 浏览书架 | 最近与收藏支持封面网格和列表，分别记忆显示方式。显示名称、最近打开时间和文件大小；名称按当前文化比较，时间按最近打开时间，两者均支持升降序，同值用路径稳定排序。封面异步加载，加载前显示占位；宽度变化时调整列数。空最近、空收藏、空文件夹分别提供对应入口或提示。 |
| F05 收藏归类 | 星标可直接收藏或选择收藏文件夹；一个条目有一个可空文件夹 ID。支持新建、重命名、按文件夹筛选、移动归属及取消收藏。名称需要校验重复。删除收藏文件夹后，条目仍为未分类收藏。 |
| F06 拖放 | 把书架条目拖到收藏区或文件夹，也可拖入 Finder 里的 PDF。对目标显示悬停反馈，取消时清除。窗口空白区接收文件用于打开；缩略图侧栏接收文件用于插页；目标区域决定动作。 |
| F07 条目操作 | 支持打开、定位源文件、管理收藏、压缩导出等上下文动作，按文件状态决定可用性。长文件名截断时仍可辨认。最近和收藏（含收藏文件夹）的网格、列表均须处理文件路径失效。 |
| F08 批量管理 | 进入选择模式可逐项选择、全选和取消。收藏区取消收藏仍保留最近记录；从最近移除会一并清除该条目的收藏、位置和个人书签。选择同时删除源文件时，列明后果并移至系统废纸篓，已打开的 PDF 要先关闭。多文件部分失败时根据每项结果更新书架。 |

实现入口：[书库文件操作](../windows/src/PDFDesk.Engine/PdfLibrary.cs)、[书架](../windows/src/PDFDesk.App/MainWindow.Shelf.cs)、[收藏](../windows/src/PDFDesk.App/MainWindow.Favorites.cs)、[打开与新建](../windows/src/PDFDesk.App/MainWindow.xaml.cs)。

## 3. 标签、窗口、文件身份和保存

| 编号 | 行为合同 |
|---|---|
| W01 窗口与标签 | 单应用实例接受后续打开请求；同一进程可有多个阅读窗口。标签独立持有文档、阅读位置和编辑历史，选中时延迟加载。可回主页再返回，或新建窗口。移动标签到新窗口应保留当前内存编辑和位置。 |
| W02 同文档并排查看 | 「在新窗口查看」建立只读快照。同一底层文件只允许一个编辑者；使用打开句柄的文件身份识别别名、路径替换等情况。快照保持自己打开时的版本。提示已有更新，允许重新载入、前往编辑窗口、在没有编辑者时开始编辑，或编辑独立副本。 |
| W03 原位保存 | 修改后标签显示未保存标识。提交浮动文本编辑器和焦点表单，先在临时位置生成完整 PDF，再比较磁盘版本并替换。版本至少包含长度、修改时间和内容摘要。外部替换恰好保持长度和时间时也须拒绝覆盖。成功后更新身份、书签版本、脏标识及编辑历史。 |
| W04 另存与恢复 | 普通另存为写入当前内存内容、保存对应书签并打开目标文档。原件路径消失后保留已打开字节和未保存编辑，限制继续改写，提供「保存副本」。恢复时先验证新文档可打开且保存期间没有新编辑，再接管原标签的位置。取消选址或写入失败时可继续处理原标签。 |
| W05 关闭与退出 | 先处理整理草稿、提交输入，再对脏文档提供保存、放弃、取消。多个文档显示名称和全部保存动作。取消或保存失败应保留尚待处理的文档。正在导出的窗口提示完成或取消任务。区分关闭标签、关闭窗口到后台、退出整个应用。 |
| W06 会话 | 默认启用恢复。持久化各窗口的文件顺序、活动标签或主页、收藏筛选、只读标签和文档位置。恢复标签可延迟打开；切换回来恢复页码、缩放、视图旋转、侧栏、列数和滚动比例。读取旧配置时兼容双页布尔值与新版列数字段。 |
| W07 后台入口 | Windows 可关闭到托盘，菜单列出各窗口并提供恢复、新建窗口、打开 PDF 和退出。macOS 方案以 Dock、窗口菜单和可选菜单栏项目承接；明确「关闭窗口」与「退出应用」的生命周期。 |

**保存冲突验收。** 在窗口 A 编辑第 2 页，窗口 B 保持旧快照。A 保存后，B 应能读到原快照并识别新版。再从外部替换原文件，A 的下一次原位保存须提示冲突。移走原文件，执行保存副本并重开，核对最后输入的文字、书签和页序。失败分支必须保留可恢复的内容。

## 4. 阅读、导航、查找和截图

| 编号与功能 | 操作与实现细节 |
|---|---|
| R01 连续阅读 | 支持单列、双列、三列及混合纸张尺寸。按每页实际宽高分行定位，维持页间距、页边距；从视口位置计算当前页。页码控件对用户从 1 计数，引擎从 0 计数。页码跳转、上一页/下一页、首尾页、逐屏和逐行滚动均须可达。 |
| R02 缩放 | 10%–640%，步进倍率 1.25，支持实际大小、预设比例、适合宽度、适合页面。滚轮组合键或触控板缩放围绕指针或手势锚点，重排后锚点附近内容仍可见。窗口大小变化时重新计算适配比例。 |
| R03 旋转与外观 | 向左或向右旋转 90°，视图旋转与 PDF 页自身旋转组合。缩略图、选区、查找命中、链接、表单、画笔、签名与文字框共享变换。夜间阅读对呈现结果反色，与界面主题独立。 |
| R04 侧栏 | 可收起；页面缩略图保持纸张比例、按需绘制，当前页与多选页有独立反馈。章节用树展示 PDF 内置目录。个人书签支持添加、命名、跳转、重命名和移除；按文档版本保存在本地。 |
| R05 导航与链接 | 章节、书签、内部链接和页码可定位目标；支持导航历史后退和前进。外部网页链接仅接受 HTTP/HTTPS，确认后交给系统浏览器。验证内部命名目标、旋转页和无效目标。 |
| R06 选词与复制 | 鼠标拖选文本、双击选词，通过 PDF 文字层的字符和边界生成选区，可复制或直接做标记。触摸下普通拖动用于滚动，长按约 500 ms 或双击选词，可扩选并打开上下文菜单。 |
| R07 全文查找 | 打开紧凑查找栏，可用选中文本首行预填；支持大小写选项、显示命中数、高亮及上/下一项。按页后台搜索，逐步交付结果；新查询取消旧任务，关闭清除高亮。空查询、搜索中和完成无命中分别处理。单页上限 5,000 个命中。 |
| R08 命令面板 | 快捷键或菜单打开，输入筛选命令或最近文档；纯数字可跳页。方向键切换、回车执行、Esc 关闭。命令的作用窗口、活动文档和选区必须一致。 |
| R09 专注阅读 | 单独提供进入和退出入口，收起干扰阅读的工具和任务区；Esc 恢复。普通阅读快捷工具条支持折叠和展开。 |
| R10 演示 | 独立全屏逐页显示，从阅读位置开始。方向键、翻页键、空格、点击或触摸翻页；鼠标右键或非鼠标指针点左侧六分之一区域返回，其余区域点击前进。在末页再次点击前进区域退出，末页按键盘下一页停留在末页。Esc、F5 或退出控件结束，阅读器跟随最后展示页。 |
| R11 截图 | 选择矩形或自由轮廓，在页面上拖动，松开复制到系统剪贴板。边缘自动滚动，允许跨视口、跨页；坐标绑定文档。按当前排版、旋转、显示倍率与夜间模式重新渲染，自由轮廓输出带透明区域的 PNG，并提供普通位图兼容表示。最长边受设备能力与 4096 px 限制。取消、失去捕获或切换文档时丢弃过期结果。 |

## 5. 批注、文字、图片和签名素材

同一时刻只激活一种页面工具。普通阅读、文本输入、表单焦点、对象移动、画笔和截图对同一拖动有不同含义。输入路由要在按下时确定对象，连续手势只认发起它的指针。Esc 收起当前工具或结束当前编辑，之后快捷键重新作用于文档。

| 编号与工具 | 编辑行为与 PDF 表示 | 验收重点 |
|---|---|---|
| A01 画笔 | 支持颜色、线宽、透明度，单独记忆工具参数。默认红色 `#E22222`、2.5 pt、全不透明。绘制时实时预览，落笔写标准 Ink 批注；跨页手势按页切分，笔与触摸并用时忽略误触。 | 从第一页穿过页间空隙画到第二页，一次撤销和重做后，两页各只有对应笔迹。 |
| A02 文字标记 | 拖选文字或对既有选区执行高亮、下划线、删除线，用文字四边形写标准标记批注。荧光笔默认 `#FFD200`、不透明度 0.4，与画笔样式分开记忆。 | 在旋转的双列页逐行选择，标记随字形走，重开仍能识别。 |
| A03 橡皮擦 | 擦除轨迹与墨迹几何求交，保留未擦到的线段，支持调整擦除宽度，默认 16 pt。呈现擦除区域预览。 | 擦掉长线中段，两端保留；撤销恢复整线，其他类型批注保持完整。 |
| A04 便签 | 点击页面定位，输入正文后创建标准 Text 批注，把内容存入 `/Contents`。新建弹窗显示页号并聚焦正文，纯空白不能提交，保存时去除首尾空白。已有标记打开阅读面板，提供页号、正文与删除；只读快照隐藏删除。 | 第三方阅读器可看到便签正文；叠放批注中删除后撤销，层序恢复。 |
| A05 文字框 | 点选页面位置打开输入框，提交后拖对象角点设定框宽，原生编辑控件支持中文输入法、多行、选择与剪贴板。可再次编辑、移动、改宽、改字体字号、颜色、粗斜体、下划线、左中右及两端对齐。默认 Helvetica、14 pt、黑色、左对齐。调整框宽时按原字号重排。写入失败保留编辑器和输入。 | 中英混排换行后缩窄，文字换行、字号不变；重新打开仍可编辑，展平后可在正文查找。 |
| A06 文字外观与字体 | 文字框是 Stamp 内的真实 PDF 文本对象。原文保存在 `/Contents`，私有 `/PDFDeskStyle` 记录宽度、对齐及下划线等信息。按行定位，两端对齐可分词输出，下划线画成路径。Windows 支持系统中可用的微软雅黑、宋体、等线；嵌入前检查许可并生成所需字形的 TrueType 子集。 | 在缺少创作机字体的设备核对中文、标点、字重及换行；macOS 字体替换时回读旧样本。 |
| A07 普通图片 | 选择 PNG、JPEG、BMP、GIF 或 TIFF，显示半透明预览，点放或拖出大小。普通滚轮滚动，组合滚轮调整放置尺寸。保留图片本身背景和透明度，将图像写入 Stamp。 | 放置后可点选、移动、拖角等比缩放、删除和撤销；与文字框缩放语义分别测试。 |
| A08 创建签名 | 提供手写、输入姓名、导入签名图片三种方式；支持黑/蓝墨色、清除重来和本机手写字体。图片可选去纸张背景，保留已有透明通道，按墨迹边界裁切并留边；预览结果，识别不可靠时保留原图并告知。 | 测白纸照片、光照不均、已有透明 PNG 和没有清晰笔迹的图；普通图片导入无需走签名去底。 |
| A09 签名复用与放置 | 签名素材在本机保存，可选取复用和删除。预览、定位、等比缩放、移动与图片共用 Stamp 流程。分别记忆图片及签名放置宽度，签名默认 180 pt。 | 删除素材、关闭应用后重开签过的文件，页面签名仍存在且位置正确。 |
| A10 对象和历史 | 对支持的批注显示选中边界、移动或角点控制柄、右键及删除键动作；重建批注时恢复索引和叠放顺序。每份可编辑文档统一管理可撤销的批注和页面操作，菜单显示下一项动作。参考预算 50 步、64 MiB 快照，执行新操作截断重做分支。 | 把页面移动和对象编辑交错执行，再撤销、重做；失败的重放可以重试且不重复创建对象。 |

## 6. 表单、文档信息和既有数字签名

- **D01 填写 AcroForm。** 支持文本、复选框、单选组、组合框、列表框。由 PDFium 表单环境处理命中、焦点、字符和按键，再绘制控件外观及字段边界。只读字段按其属性处理。切页、保存、打印和关闭前提交焦点中的值。使用旋转过的表单填写、保存并重开，核对值与显示外观。
- **D02 字段文字样式。** 右键调整颜色和字号，支持键盘调整大小、粗体、斜体。更新 Widget 默认外观字符串 `/DA`，复用表单字体资源；渲染验证变体可用，若文字变空则回退。遇到继承外观且缺少可安全复用的资源时提示原因。
- **D03 文档属性。** 分组展示标题、作者、主题等元数据、创建及修改时间、文件路径、大小、PDF 版本、页数、当前纸张尺寸、混合尺寸提示、加密与权限、Tagged PDF、表单类型、附件数和字体。解析 PDF 日期即时区，纸张显示常用名称、毫米及 pt。缺值有明确显示；字体后台扫描最多 50 页。

## 8. 输出、压缩、打印与分享

- **O01 展平批注。** 用户确认后逐页将批注及已填写表单的外观合并为页面内容。分别记录有改动、无可展平内容和失败的页面。成功页仍可保留，部分失败须报告页号；展平改变对象身份，清除过期撤销历史、缩略图和文字缓存。要同时保留可编辑稿时，将展平结果另存。用包含文字框、墨迹、高亮和表单的文件核对画面，再检查对应对象已无法单独编辑。
- **O02 系统打印。** 针对当前打开的内容创建打印快照，包含未保存修改；原标签关闭后已启动的作业仍使用该快照。提供预览、页段、灰度或彩色、实际大小或仅缩小超出可打印区域的页面。Windows 默认灰度、超大页缩小，预览参考 96 dpi、输出 150 dpi。macOS 可采用系统打印面板；用混合纸张、横向页及边缘有标记的小页核对居中、边距和比例。
- **O03 分享 PDF。** 「复制文件路径」提供文本；「复制 PDF 文件」提供能在文件管理器粘贴的文件对象。带未保存编辑时，从已打开内容生成同名的独立临时副本；原路径被替换时也须分享用户正在看的版本。清理过期分享副本时给接收方保留粘贴时间。页剪贴板、系统文件、选中文字、截图四种复制分别路由。
- **O04 压缩入口和交互。** 书架或活动文档启动。对话框显示原大小、档位、估算或准确结果、节省比例，支持更改输出目录、保存副本、替换并重载原文件、导出后自动打开。副本默认名含档位，重名递增。可单独计算准确大小；实测无缩小时仍允许保存副本，关闭替换选项。

| 压缩档位 | JPEG 质量 | 合格照片最长边 |
|---|---:|---:|
| 极致压缩 | 42 | 1600 px |
| 均衡 | 72 | 2400 px |
| 高质量 | 92 | 4096 px |

**O05 压缩算法。** 基于输入快照，用 qpdf 枚举 PDF 对象与原始流。自定义重采样仅处理满足条件的 8 bit RGB JPEG（DeviceRGB 或三通道 ICC），跳过带 Mask、SMask、自定义 Decode 或特殊解码参数的流。核对解码尺寸，仅缩小长边，不放大小图，编码结果更小时才替换该流。随后生成对象流、重压 Flate、执行图像优化；以 qpdf 完整性检查及重新打开验证页数作为交付条件。保留文本、矢量和页面结构。抽样估算按合格照片字节加权，最多取三个样本；大批同类扫描页可取一个。估算超时、样本过大或代表性不足时，提供准确计算。

**O06 导出队列和文件安全。** 副本导出可后台运行，队列支持展开、折叠、查看阶段、进度和取消。全应用最多同时执行两个副本导出；同一源文件重复请求定位已有任务，同一目标不能被两个任务同时写入。先提交编辑、生成快照，再写目标目录内的暂存文件。替换前复核源文件版本、标签、编辑修订及正在输入或整理的状态；任一变化均中止替换。成功替换后更新书签摘要、可重载标签与封面。取消或失败应释放任务槽、目标占用及临时文件。检查源文件摘要与页数，验证中途取消没有留下半成品。

实现入口：[压缩对话框](../windows/src/PDFDesk.App/Controls/CompressionDialog.xaml.cs)、[压缩算法](../windows/src/PDFDesk.App/Services/PdfCompression.cs)、[队列与提交](../windows/src/PDFDesk.App/MainWindow.Compression.cs)、[展平](../windows/src/PDFDesk.Engine/PdfDocument.Flatten.cs)、[打印](../windows/src/PDFDesk.App/Services/PrintService.cs)、[复制文件](../windows/src/PDFDesk.App/Services/PdfClipboard.cs)。

### 移植时可直接使用的细节

- 书架「找回文件」让用户重新定位 PDF。若新路径已有另一个书架条目，提示重新选择；成功时迁移旧记录、会话路径和阅读位置，清理旧封面。取消文件选择器时保留原记录。
- **文件缺失弹窗验收（F07）。** 在最近和收藏中分别用网格、列表打开已移动或删除的 PDF。弹窗点名文件，提供「定位 PDF」、与当前列表对应的移除操作及「取消」。最近的「移除记录」使用中性底色和危险色文字，正文明确会清除收藏、阅读位置和书签；确认后同步清理缓存封面和关联会话，并从最近与收藏消失。收藏（含文件夹）提供普通次要按钮「取消收藏」，保留最近记录、阅读位置、书签和缓存。两种操作均不改动磁盘上的 PDF。检查「定位 PDF」使用强调色，「取消」保持中性并获得初始焦点；中英文按钮标签均须完整显示，Esc 或取消保留原状；移除后重启验证结果。
- 画笔宽度范围为 1–12 pt、步长 0.5，透明度范围为 10%–100%、步长 5%。橡皮擦宽度为 4–64 pt、步长 1。工具参数面板提供色样、当前数值和样例预览。Windows 鼠标悬停约 120 ms 展开选项、离开约 220 ms 后收起，移入浮层时允许继续操作。
- 西文字体提供 Helvetica、Times、Courier 三类选择。表单中 Backspace、Delete、全选、Shift+方向键、Enter、Tab 和 Esc 需要分别验证，特别是输入法组合期间的回车。文字框、表单字段和普通阅读各自管理焦点。
- 发出未修改文档的分享快照时，优先保留原始字节，避免重新编码已有数字签名。Windows 分享缓存清理以一天为阈值。对已有签名的 ByteRange 应区分覆盖、不完整和无法判断；遇到格式损坏或范围重叠时显示无法判断。

### 11.2 文件打开、只读、覆盖与退出

| 场景 | 执行规则 |
|---|---|
| 带文件请求启动，同时有待恢复的会话 | 先保留明确请求的标签作为活动标签，补回仍存在且尚未打开的会话路径。没有明确请求时恢复上次选中项；同一 PDF 在两个窗口的页码和缩放可分别恢复。脚本参数的页码从 1 起，缩放 1.0 表示 100%；两个参数同时提供时先缩放再跳页。 |

### 11.3 阅读手感、命令优先级与输入

- **排版。** 行内各页顶部对齐，下一行取本行最大高度，末行不足列数时整体水平居中。页面间隔基准 16，常规外边距 24；整个文档矮于视口时垂直居中。适宽遍历所有行，取每行可容纳的最小倍率；适页使用当前页所在整行的总宽与最大高度。改变列数时，若此前为手动缩放，进入适宽。跳转至同一行的右页或底部数页时，多个页可能对应同一滚动偏移，页码应保留用户刚选的目标。
- **缩放和导航。** 菜单预设为 50%、100%、150%、200%。鼠标缩放保存指针下的页内点，工具栏缩放以当前阅读页的可见部分为锚点，不能简单按倍率乘整个文档的滚动偏移。↑/↓ 各滚动三行，PgUp/PgDn 和 Shift+Space/Space 各滚动视口的 90%。按钮有焦点时空格仍可激活按钮；侧栏列表保留自己的方向键导航。
- **选词和搜索。** 普通文本选区局限在起始页，反向拖选仍返回同一顺序的文字，多行结果按行生成矩形。双击先尝试编辑命中的可编辑文字框，再尝试选词；选词从命中字符向两侧扩展到空白。搜索输入停顿约 200 ms 后执行，匹配大小写可切换，界面使用子串搜索。首项到达即定位并显示「当前位置 / 已找到数量」语义，前后遍历可首尾循环。查找栏打开时切标签，清除旧文档高亮并在新文档执行现有查询。
- **命令面板。** 每次打开时按活动视图重建命令，加入最近 8 份文档。有效页号的跳页项置顶；其余忽略大小写，按前缀、子串、按序字符匹配排名，同级按名称排序。默认选第一项，点击外部失焦关闭。只读窗口仍提供查看、提取和另存命令。
- **Esc 逐层退出。** 文字框内按 Esc 提交文字。窗口级依次处理截图、演示、命令面板、工具参数浮层、查找栏、专注模式、进行中的贴图、已选对象和当前工具。一次按键处理一层；收起参数浮层后工具仍可用。拖动书架卡片时 Esc 取消拖动。
- **触控与数位笔。** 长按选词容许约 12 逻辑单位的抖动。链接、字段和贴图对触摸增加 8 单位命中容差，换算成页内距离时除以缩放。缩放柄视觉尺寸为 10，触摸命中基准扩大到 24。点放与拖出贴图的移动阈值，鼠标为 8、触摸为 16。手写或擦除捕获发起指针，在动作结束或被取消时交还滚动与捏合。支持系统识别的笔尾橡皮擦或倒置笔。
- **截图与演示。** 截图分裂按钮的主区域重复上次选择的形状，再点一次取消；切换形状可直接启动。截图前先提交待输入内容，靠近边缘 24 单位开始自动滚动，约每 32 ms 更新轮廓。演示使用独立临时全屏窗口，在原阅读窗口所在显示器上按比例居中，以黑色填充留边。当前页优先绘制，后台预取前后各一页，远页释放；继承阅读旋转及夜间状态。

### 11.5 页面结构、导出、打印与反馈

- **选页与草稿。** 页剪贴板在应用进程内存中存独立 PDF 字节，可跨窗口，在源标签关闭后继续粘贴。复制或剪切按文档顺序取页；普通粘贴插到最后一个选中页后，无选区则插到当前页后。提取建议文件名包含原名和选页范围。整理器的复制将新页集中插到最后一个选中项后；撤销恢复操作前的选区，重做恢复操作结果选区。所有页都选中时禁止删除；连续页移动到原位置不会增加一条历史。
- **撤销与失败。** 写入新对象前先校验几何和图像缓冲，删除前捕获能重建的批注描述。撤销删除要恢复原索引和叠放顺序。重放遇到对象已经变化时保留历史项供重试；跨页操作已处理的部分须回滚。历史预算超限时优先淘汰旧项，单条较大的最新快照允许保留。书签状态写失败时从约 2 秒开始退避，到 60 秒封顶，重试状态写入即可。
- **压缩默认值与复用。** 默认均衡档、保存副本到源目录、勾选导出后打开。自动命名如 `报告-均衡压缩 (2).pdf`，避开已有文件和正在写入的目标。快速估算以磁盘文件为输入，限时 6 秒；准确计算和实际导出由已提交的编辑生成快照。准确计算若候选文件比快照大，则选快照作输出；再与界面显示的原磁盘大小比较，决定可否替换。切回最近实测的档位可复用已生成结果。
- **压缩抽样边界。** 快速估算遇到超过 12 MiB 的对象索引、合格照片不足原文件 15%、抽中照片大于 8 MiB 或超过 1200 万像素时放弃估算。对至少 50 张图、照片占文件至少 90%、绝大多数图尺寸相近的扫描件，可选一个按字节加权的样本。不能快速估算时显示「—」和准确计算入口，仍可直接保存副本。
- **队列状态。** 等待中 → 准备文件 → 压缩百分比 → 校验并保存；请求取消后进入「正在取消」并禁用重复取消。任务完成后可打开所在文件夹。最后一个任务结束后隐藏队列，下次任务出现时默认展开。
- **打印。** 系统面板提供全部或指定页、份数、方向、纸张、单双面、逐份打印，以及应用自己的颜色和缩放选择。按每页纸张可打印区域计算；仅缩小时倍率取 1、可用宽比、可用高比中的最小值。Windows 输出渲染最长边上限 8192 px，灰度转换保留 Alpha。打印用原 PDF 页面和已提交编辑；阅读区反色、查找选区和侧栏不会打印。
- **弹窗和反馈。** 同一窗口仅承载一个模态决定，重复触发按取消处理，其他窗口仍独立。移到废纸篓的确认默认焦点为取消，列出将处理的文件；展平确认同样默认取消。常规通知以 5 秒为计时基准，窄于 360 逻辑单位时动作纵排。XFA 与已签名提示属于文档本身，手工关闭后应记住该文档视图已经看过，避免每次切回重复提示。

## 12. Windows 与 macOS 的 PDF 文件兼容约定

迁移时要验证两条路径：Windows 创建的对象能否在 Mac 上继续编辑，以及 Mac 保存后的对象能否回到 Windows 继续编辑。第三方阅读器用于核对可见外观、表单值和链接。以下字段是 Windows 0.0.47 已在读写的文件格式，适合直接做兼容性测试。

### 12.1 可编辑文字框的文件表示

文字框使用 Stamp 批注。写入时同时保存原文、外观流和编辑样式，各自承担不同用途。

| 位置 | 写入与读取规则 |
|---|---|
| `/Contents` | 保存完整原文，包括显式换行。重开编辑时从这里取全文。CRLF、CR、LF 在排版时统一为换行；一行可能拆成多个绘制对象，不能通过拼接绘制对象重建段落。 |
| 外观流中的文本对象 | 使用真实字体、字号、填充色及位置。回读时寻找具有有效字号、可识别字体的文本对象；无法读取填充色时默认黑色。无可识别文字对象的第三方 Stamp 应继续按其现有外观显示，不能因含有描述文字就当成 PDF Desk 文字框重写。 |
| `/PDFDeskStyle` | PDF 字符串，字段用空格分开。写入顺序为 `U`、`A`、可选 `F`、可选 `W`。例：`U1 A2 W144.5` 表示下划线、右对齐、框宽 144.5 pt。读取时按字段首字母识别，忽略未知或无法解析的字段。 |
| `U` 与 `A` | 写入 `U0` 或 `U1`。对齐枚举为 0 左、1 中、2 右、3 两端。遇到旧文件缺少整个样式键时，默认无下划线、左对齐、自动宽度。 |
| `F` 与 `W` | 使用本机字体或回退字体时，`F` 后紧接用户选择的 PostScript 字体名，如 `FMicrosoftYaHei-Bold`，用于恢复字体选择。回读优先尝试此名，其次识别实际文本对象字体，兼容字体子集前缀。正数宽度写成 `W` 加不依赖系统区域的小数，最多三位小数；自动宽度省略此项。 |

**排版复现。** 相邻基线间距取字号的 1.2 倍；先在局部坐标中排版、测量，再把整个文字块移到指定页内左上点。无空格的过长中文串可按文本元素折行。下划线在每个有字的行底绘制矩形，厚度取 0.4 pt 与字号除以 14 的较大值。测试时用居中、右对齐及两端对齐的混排文字，检查重开前后的换行和边界框，尤其是只有一行的定宽框。

**中文嵌入边界。** Windows 为回退字符分配 CID，生成子集字体、CID 到字形映射和 ToUnicode 映射；这使得即使不同字符使用相同字形，也能保留正确的文本映射。写入前验证字形存在，以及字体允许编辑嵌入和子集化。当前 Windows 子集路径遇到 UTF-16 代理字符会返回失败，包含常用汉字的测试通过并不能说明所有 emoji 与扩展汉字均可写入。Mac 端若扩展字符覆盖，要另测展平后的提取、跨端显示与再次编辑；写入失败应保留输入并让用户可选择其他字体。

实现依据见[文字对象与样式编解码](../windows/src/PDFDesk.Engine/PdfDocument.Text.cs)、[字体子集](../windows/src/PDFDesk.Engine/PdfTextFallback.cs)和[文字对象往返测试](../windows/tests/PDFDesk.Tests/TextObjectProbeTests.cs)。

### 12.2 墨迹、橡皮擦与透明印章

**墨迹保存两份几何信息。** 标准 Ink 批注的 `/InkList` 保存可编辑的中心线，标准 PDF 外观流描绘实际着墨区域。PDF Desk 还把剩余墨迹轮廓写进批注字符串 `/PDFDeskInkFootprint`，内容是 JSON。下面是格式示例，坐标使用 PDF 页空间，颜色各通道取 0–255。

```json
{"Loops":[[10,10,20,10,20,20,10,20]],"R":226,"G":34,"B":34,"A":255}
```

每条轮廓是交替的 x、y 数值，至少三个点，数值须有限。画笔和橡皮的轨迹均扩张成圆连接、圆端点的覆盖区域；Windows 用 Clipper2 对两个区域求差。先按相交区域裁切着色轮廓，再更新能够用中心线表达的部分。窄橡皮只擦去粗笔画内部时，剩余轮廓可含孔；外观流用奇偶填充显示孔洞。遇到没有有效私有轮廓的旧文件时，从标准中心线与线宽重建，宽度缺失或非正时按 1 pt。验收要在粗墨迹中间擦出一个小孔，保存、在另一端重开、再沿孔边擦一次，然后撤销第二次擦除。

**印章及叠放。** 图片和可见签名使用带图像对象的 Stamp 并设置打印标志。引擎入口接收每像素 4 字节的 straight BGRA；若平台绘图库使用预乘 Alpha，在边界处转换一次。回读带软遮罩的图像要恢复透明度。缩放已有图片时用原始像素和新矩形重新生成外观，再恢复应有层序；单改批注矩形会导致多次缩放时外观与选框逐渐错位。表单页显示时先绘制页面与表单，再合成应在字段上方的印章；临时修改的可见性须在绘制后恢复。

**文字标记与便签。** 多行高亮按每行选区写四边形，批注外框取所有四边形的并集。页自身旋转或裁剪时调用相同的页坐标转换，避免只翻转 Y 轴。便签默认图标为 20 pt 的折角纸张，使用矢量外观，色值为 RGB(255,219,117)，正文单独写入 `/Contents`。打印时也应能看到图标。

实现依据见[墨迹轮廓格式](../windows/src/PDFDesk.Engine/InkFootprint.cs)、[擦除与重放](../windows/src/PDFDesk.Engine/PdfDocument.InkErasing.cs)、[印章](../windows/src/PDFDesk.Engine/PdfDocument.Stamps.cs)、[透明度与字段叠放测试](../windows/tests/PDFDesk.Tests/StampTests.cs)。

### 12.3 表单外观、页间引用与文件替换

| 对象或操作 | 实现细节及失败处理 |
|---|---|
| 改字段的字号或颜色 | 先提交焦点字段的值，再解析 Widget 自身的 `/DA`，例如 `/Helv 12 Tf 0 g`。保留字体资源和无关指令，处理灰度 `g`、RGB `rg`、CMYK `k`；字号 0 表示自动适配。改写后使缓存页失效，重新加载字段外观。在独立阅读器里既要检查字段值，也要检查实际画出的字。 |
| 改字段粗体或斜体 | 沿用已知资源家族推导变体，资源名指向 AcroForm 的 `/DR`。Windows 对可能更换字体的操作比较字段绘制前后是否仍有字迹；原来有字、改后变空则恢复原外观并提示失败。不能将界面上暂时套用字体视为已成功写入 PDF。 |
| 抽取或插入含链接的页 | 有 AcroForm 字段树、页内直接目标或 GoTo 动作时走保留文档级引用的路径。提取前把旧式 Catalog `/Dests` 和 `/Names/Dests` 名称树中的本地目标展开为明确目的地数组。遍历名称树时去重；保留 URI 动作。若某目标页没有被提取，独立子文档无法继续跳到原文件中未随行的页。 |
| 在原文档内复制链接页 | 被复制页可以指向选区以外、但仍在原文档里的目标页。Windows 在此情形用 qpdf 从同一源文件重复选择页面，避免先导出子文档时丢失目标。连续页压缩为 1 基页段，例如内部索引 `[0,1,2,5]` 传给 qpdf 为 `1-3,6`。 |
| 撤销批注删除 | PDFium 新建批注会追加在末尾。重建时将追加对象在页的 `/Annots` 数组中放回原索引；数组可能直接挂在页面，也可能是间接对象。恢复层序失败时移除已追加的临时对象，保持修订号可重试。 |
| 原位保存遇到故障 | 提交表单焦点后，文档干净则直接返回。有修改时在同目录写暂存并强制刷盘，核对源版本后带备份原子替换。若替换失败且原路径已消失，尝试把备份移回；恢复也失败时向用户显示仍可取回原稿的备份路径。整段流程成功后才更新保存版本和脏标识。 |
| 读取数字签名覆盖 | 将 ByteRange 按「偏移、长度」成对处理。缺失、负值、越界、重叠或乱序返回「无法判断」。合法范围未从文件头开始、未到文件末尾，或中间空隙显著超过签名内容十六进制表示所需长度时，报告「存在未覆盖内容」。Windows 对已知签名内容长度采用 `2 × 字节数 + 2 + 64` 的总空隙上限。通过覆盖检查仍须显示「未验证签名」。 |

实现依据见[字段外观解析](../windows/src/PDFDesk.Engine/FieldAppearance.cs)、[字段重绘](../windows/src/PDFDesk.Engine/PdfDocument.Forms.cs)、[页间引用重写](../windows/src/PDFDesk.Engine/PdfDocument.PageTransfer.cs)、[保存和恢复](../windows/src/PDFDesk.Engine/PdfDocument.Annotations.cs)、[签名覆盖判定](../windows/src/PDFDesk.Engine/SignatureCoverage.cs)。

## 13. 交给开发 AI 的实施顺序和验收

1. **先验证 PDF 写入能力。** 用一份混合表单、内部链接、中文文字框及已有批注的样本完成打开、插页、编辑、保存、重开；用 macOS 预览和 Windows PDF Desk 交叉检查外观及可编辑性。把这个样本加入后续回归。
2. **搭建阅读与文档生命周期。** 实现 F01–F04、W01–W06、R01–R07 和文件冲突保护。用千页 PDF 检查首屏、连续滚动、搜索取消、内存、句柄和关闭标签后的资源回收。
3. **打通编辑与页面结构。** 实现 A01–A10、D01–D04、P01–P05，每类编辑都走「执行→撤销→重做→保存→重开」。为跨页笔迹、选区旋转、表单字段树、链接目的地和旧快照分别留回归用例。
4. **完成桌面操作和输出。** 交付收藏管理、所有窗口模式、截图、分享、压缩、展平、打印、设置和键盘路由。逐项核对前文编号，英文和简体中文各走一次主流程。
5. **交付证据。** 对每项记录实现入口、测试样本、操作步骤、预期和实测结果；把实机打印、键盘、VoiceOver、菜单栏、沙盒授权及跨屏显示分别登记。Windows 打包脚本与版本号是现有仓库的发布约定，macOS 的最低版本、CPU 架构、签名公证及商店分发渠道由 macOS 项目另行确定。

| 端到端用例 | 输入和动作 | 通过条件 |
|---|---|---|
| T01 文件和状态 | 两个同名文件分别原位打开、复制导入；收藏归类、换列表、退出并恢复 | 副本独立；打开的是预期文件；标签顺序、书签、位置和视图回到原状态 |
| T02 只读与外部变动 | 同一文件开两个窗口。编辑、保存、从外部同长度替换，再移走源文件并保存副本 | 始终只有一个可编辑视图；旧快照仍可阅读；冲突不能覆盖外部文件；副本含未保存编辑 |

| T06 导出竞争和错误 | 对同一源重复压缩，两份输入指向同一目标，计算准确大小后编辑源文档，尝试替换并取消排队任务 | 正确定位重复任务、拒绝过期替换；没有半成品；签名/加密文件有明确提示；源文件保持可读 |

| T09 草稿与同形页面 | 五页文档在原第 4 页加书签。选第 2、4 页执行复制，撤销、重做，随后在外部替换源文件并尝试保存 | 复制得到原页序 1、2、3、4、2、4、5；书签只跟随原第 4 页。原位保存失败后可另存草稿，外部文件字节保持一致 |

| T11 多列与放映末页 | 用含横纵页的五页文档切三列，在 30% 缩放下点击末行右侧的页，再从末页开始演示。分别用下一页键、普通点击、右键和可用的触摸输入 | 页码保持选中的页，末行整体居中。末页下一页键停留、普通点击退出；右键或触摸左侧六分之一区域回到上一页 |
| T12 同一文件的两种窗口 | A 修改文字且尚未保存，分别从标签菜单执行「在新窗口查看」和「移动到新窗口」 | 查看得到磁盘已保存版本；移动保留未保存文字和撤销历史，原窗口不再保留被移动标签。旧快照能独立选择和截图 |
| T13 命令焦点与查找竞态 | 连续输入两个不同查询，首项出现后换标签，再从末项跳下一项。在文字框、表单、侧栏缩略图和普通阅读区分别执行同一组编辑快捷键 | 最终只显示当前文档和当前查询的命中；末项回到首项。字段输入、书签、页剪贴板及文档撤销各自只响应所属上下文 |
| T14 废纸篓与配置并发 | 选两份 PDF，一份仍打开、一份已关闭，确认同时删除源文件。另开两个窗口分别更改收藏与阅读位置，按相反顺序保存状态 | 展示失败文件及原因，成功文件进废纸篓并移除其记录。两个窗口各自的收藏变更和位置均保留 |
| T15 输入照片与签名 | 选带 EXIF 旋转的手机照片、透明 PNG、白纸签名各一份；创建签名后取消放置，再从签名库选取放入表单字段上方 | 方向正确，透明区域透出字段；取消放置后素材可再用。自动跳过去底不改变偏好，重复缩放和重开后不会出现白底或鬼影 |
| T16 压缩的两种大小 | 对照片占比低的 PDF 打开估算，计算准确大小；在含未保存批注的文档上分别保存副本和替换，在等待队列中取消另一项 | 估算不可用时仍能准确计算；副本保留未保存批注。准确结果不比原文件小时禁用替换。取消任务进入取消中，之后释放目标，其余任务能完成 |
